      business-rule CanonicalShortcutForm "A shortcut's canonical text is its modifier tokens in the order Mod, Meta, Ctrl, Alt, Shift, followed by its key token, each separated by a plus sign; a single-character key token is upper case. Two shortcuts are the same shortcut exactly when their canonical texts are equal." — "Defines the canonical text of a shortcut, on which shortcut identity rests."
      business-rule ConflictReporting "A candidate matching an existing normalized shortcut reports the matching binding as a conflict." — "Defines when an existing assignment is surfaced as a conflict."
      business-rule EscapeCancels "Escape cancels the active recording and leaves the committed shortcut unchanged." — "Defines cancellation while recording."
      business-rule ModMapping "Mod resolves to Command on macOS and Control on other supported platforms." — "Defines the portable modifier mapping used during normalization."
      business-rule ReservedRecognition "A shortcut is recognized as browser-reserved when a mainstream browser acts on it before the page observes the key press, on the platform being assessed. The engine owns the recognition set. A shortcut the set does not name is reported as unreserved, which is the absence of recognition and not evidence that the shortcut is free." — "Defines which shortcuts count as browser-reserved, and how the absence of recognition is reported."
      business-rule ReservedWarning "A recognized browser-reserved shortcut produces a warning rather than being treated as an ordinary unreserved assignment." — "Defines handling for browser-reserved shortcut candidates."
