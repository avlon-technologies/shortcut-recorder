# Acceptance — shortcut-recorder

> Generated by `tools/development-package.mjs`. Executable specification: the scenarios are data, the runner is shipped, the adapter is yours. Every scenario is traceable to the semantic model (validated at package build: an unresolvable reference fails the build).

## Run

```
node acceptance/run.mjs --check                              # shape only
node acceptance/run.mjs --adapter acceptance/adapter.mjs     # execute (default adapter path)
node acceptance/run.mjs --only <scenario-name> --json
```

`MODEL_PROVIDER` defaults to `fake`; no scenario here needs an API key. The fake provider (`fake-model-provider.mjs`) is scripted per scenario under `provider`: completion order (virtual `latency`), structured `output`, `silence`, `fail` / `failuresBeforeSuccess` (retries), `malformed` output, and a `budget` (`maxCalls`, `maxConcurrent`).

## Scenarios

### `core-shortcut-behavior`

The core records and normalizes a shortcut, formats readable keycaps, cancels with Escape, and reports conflicts and reserved-shortcut warnings.

- verifies: `::ShortcutRecorder.ShortcutConfiguration.Recording.EscapeCancellation` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.Recording.KeyboardAccessibility` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.Normalization.PortableModifier` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.Presentation.PrettyKeycaps` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.AssignmentSafety.CollisionDetection` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.AssignmentSafety.ReservedShortcutWarning` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.Shortcuts.ShortcutEngine` (Service)
- realizes the declared Test `::ShortcutRecorder.CoreBehavior`
- environment: `::ShortcutRecorder.PackageDevelopment`

**given**
- Search is already assigned to Mod+K `[recorder.has-existing-bindings]`
- recording starts from the keyboard `[recorder.starts]`

**when**
- the user presses Command+Shift+P `[recorder.presses-chord]`

**then**
- the portable value is Mod+Shift+P `[recorder.normalized-value-is]`
- the shortcut is presented as readable platform keycaps `[recorder.keycaps-are-readable]`
- an already assigned shortcut identifies the conflicting binding `[recorder.conflict-is-reported]`
- a recognized browser-reserved shortcut is surfaced as a warning `[recorder.reserved-shortcut-warns]`
- Escape cancels an active recording without changing the committed value `[recorder.escape-cancels]`

### `integration-contract`

The package exposes a framework-agnostic headless core, a thin React integration, controlled and uncontrolled state, and safe server rendering.

- verifies: `::ShortcutRecorder.ShortcutConfiguration.IntegrationContract.ControlledAndUncontrolled` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.IntegrationContract.HeadlessByDefault` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.IntegrationContract.ServerRenderingSafe` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.IntegrationContract.FrameworkAgnosticCore` (Requirement), `::ShortcutRecorder.ShortcutConfiguration.Shortcuts.ShortcutEngine` (Service)
- realizes the declared Test `::ShortcutRecorder.IntegrationBehavior`
- environment: `::ShortcutRecorder.PackageDevelopment`

**given**
- the shortcut core is imported without a UI framework `[package.imports-core-without-ui-framework]`

**when**
- the core and React integration are imported in a server-rendering context `[package.imports-during-server-rendering]`

**then**
- importing does not require browser globals `[package.server-import-is-safe]`
- the React integration accepts caller-controlled shortcut state `[react.supports-controlled-state]`
- the React integration can manage shortcut state internally `[react.supports-uncontrolled-state]`
- the integration does not require package-defined styling `[react.is-headless-by-default]`
